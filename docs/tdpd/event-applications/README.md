Методология и шаблоны находятся в `.tdpd/`, исходный репозиторий —
`methodology/tdpd/`. Здесь хранятся артефакты конкретной продуктовой инициативы.
Учебный пример в `workshop/` отдельный.

Контекст, проблема и правила подтверждены для локального прототипа. Первый
прототип, две роли/повторная подача и обзор списка прошли RED → GREEN;
результаты и исторические ограничения находятся в соответствующих документах.
Итерация удобства интерфейса также прошла RED → GREEN: 31 E2E passed и сборка.
Человеческая приёмка Output/UAT ожидается. Актуальное машинное состояние —
`.tdpd/state/run-state.json`.

Проверки продукта: `npm run test:e2e`; сборка: `npm run build`.
Старый учебный набор сохранён и запускается через `npm run test:e2e:workshop`.
Локальное хранение и переключение роли демонстрируют процесс в одном браузере;
совместная работа и вход разных людей ещё не реализованы.
