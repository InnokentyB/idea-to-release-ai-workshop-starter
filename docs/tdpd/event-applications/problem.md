# PROB-001: состояние согласования и подготовки

Источник: S101/F101–F102, `context.md`.

- Пользователь: организатор мероприятия.
- Ситуация: решения и подготовка обсуждаются в чате.
- Проблема: непонятно, согласовано ли мероприятие и готово ли оно.
- Наблюдаемый результат: видны состояние заявки, решение и оставшиеся
  обязательные задачи.
- Текущий способ работы: организатор восстанавливает решения и прогресс по
  переписке (пользовательское описание в этом чате).

Сигнал успеха для UAT: организатор по конкретной заявке определяет решение,
возможность начать подготовку и оставшиеся обязательные задачи без поиска в чате.
Числовая метрика и исходные значения пока не согласованы.

Первая проверяемая часть: возврат заявки на доработку с обязательным комментарием.
Это часть общей проблемы, а не замена всего процесса согласования и подготовки.
