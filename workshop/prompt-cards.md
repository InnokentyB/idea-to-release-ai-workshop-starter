# Готовые запросы для AI-агента

Копируйте запрос целиком. После ответа агента выполняйте указанную проверку.

## Карточка 1. Создать только проверки

```text
Прочитай workshop/problem.md, workshop/spec.md и workshop/scenarios.md.
Не изменяй код приложения.

Сначала покажи таблицу соответствия сценариев S1–S4 будущим E2E-проверкам и перечисли неоднозначности. Дождись моего подтверждения. После подтверждения создай только E2E-проверки наблюдаемого поведения пользователя. Не проверяй внутренние детали React.

Запусти проверки и объясни, почему результат является правильным RED: проверки должны падать из-за отсутствующего поведения, а не из-за ошибки запуска или настройки.
```

**Проверка человеком:** тесты запускаются; причина падения связана с отсутствующей функцией.

## Карточка 2. Составить план без изменений

```text
Предложи минимальный план реализации для сценариев S1–S4.
Раздели работу на три среза:
1. событие и проверка даты;
2. задачи, отметка выполнения и счётчик;
3. сохранение и восстановление.

Не добавляй сервер, базу данных, регистрацию, внешние сервисы и новые продуктовые функции. Для каждого среза укажи, какой сценарий и какой тест подтвердят результат. Пока не изменяй файлы.
```

**Проверка человеком:** план укладывается в `spec.md`; после каждого среза есть понятная проверка.

## Карточка 3. Реализовать один срез

Замените номер и название среза перед отправкой.

```text
Реализуй только срез 1 «событие и проверка даты» из согласованного плана.
Не переходи к другим срезам и не добавляй функции вне workshop/spec.md.

После изменений:
1. запусти относящиеся к срезу проверки;
2. перечисли изменённые файлы;
3. сообщи, какое наблюдаемое поведение теперь работает;
4. укажи, что мне проверить вручную.
```

**Проверка человеком:** откройте приложение, пройдите указанный сценарий и только потом давайте следующий срез.

## Карточка 4. Полная проверка перед UAT

```text
Реализация трёх согласованных срезов завершена.
Не добавляй новые функции.

Запусти полный набор E2E-проверок и сборку проекта. Сопоставь результаты с S1–S4. Перечисли незакрытые сценарии, ошибки и ограничения. Если всё прошло, сообщи точные команды и результаты, но не принимай продукт за человека.
```

**Проверка человеком:** после GREEN самостоятельно пройдите S1–S4 и заполните `workshop/uat.md`.
