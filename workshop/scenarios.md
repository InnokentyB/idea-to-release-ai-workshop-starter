# Сценарии приёмки

Агент создаёт автоматические проверки по этим сценариям. Каждый результат должен быть виден пользователю.

## S1. Создать событие

- **Исходное состояние:** приложение открыто, событие ещё не создано.
- **Действие:** пользователь вводит название, выбирает будущую дату и сохраняет событие.
- **Наблюдаемый результат:** на экране видны название и выбранная дата; доступна форма добавления задач.
- **Что сохраняется:** название и дата события.
- **PASS:** событие видно, форма задач доступна.
- **FAIL:** событие не появилось, данные изменились или форму задач нельзя использовать.

## S2. Добавить и выполнить задачу

- **Исходное состояние:** событие создано, задач нет, счётчик показывает `0`.
- **Действие:** пользователь добавляет задачу, затем отмечает её выполненной.
- **Наблюдаемый результат:** после добавления задача видна, счётчик показывает `1`; после отметки задача выглядит выполненной, счётчик показывает `0`.
- **Что сохраняется:** текст задачи и отметка выполнения.
- **PASS:** задача и оба состояния счётчика видны.
- **FAIL:** задача не добавилась, отметка не изменилась или счётчик неверен.

## S3. Не принять неверные данные

- **Исходное состояние:** открыта форма создания события или добавления задачи.
- **Действие A:** пользователь пытается создать событие с датой в прошлом.
- **Результат A:** событие не создаётся; рядом с датой видно понятное сообщение.
- **Действие B:** пользователь пытается добавить пустую задачу.
- **Результат B:** задача не добавляется; рядом с полем видно понятное сообщение.
- **Что сохраняется:** неверные данные не сохраняются.
- **PASS:** оба ввода отклонены и оба сообщения видны.
- **FAIL:** неверные данные приняты или пользователь не понимает причину отказа.

## S4. Восстановить состояние

- **Исходное состояние:** создано событие, добавлены минимум две задачи, одна задача выполнена.
- **Действие:** пользователь обновляет страницу браузера.
- **Наблюдаемый результат:** видны прежнее событие, обе задачи, отметка выполнения и правильное число оставшихся задач.
- **Что сохраняется:** все данные и состояния из сценариев S1 и S2.
- **PASS:** после обновления ничего не потерялось и счётчик верен.
- **FAIL:** пропало событие, задача, отметка или счётчик стал неверным.

## Ручная проверка после GREEN

- [ ] Понятно, с чего начать.
- [ ] Ошибку легко заметить и понять.
- [ ] Основной путь можно пройти без подсказки ведущего.
- [ ] На узком экране текст и кнопки остаются читаемыми.
